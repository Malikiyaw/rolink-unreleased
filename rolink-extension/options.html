⚙ MCP servers (multi-server)

Add or remove MCP servers the bridge should spawn. The default roblox server is managed by the bridge itself and cannot be removed from here.

Blender setup: install uv, add the reviewed Blender preset below, then install/enable the MCP for Blender addon and start its server from Blender. The preset is safe-mode + telemetry-disabled and loopback-only (localhost:9876); it never changes a .blend file for you.

Ready-made servers

ℹ About

RoLink turns 12 AI chat sites (DeepSeek, ChatGPT, Gemini, Kimi, GLM, Qwen, Arena, Arena Agent, Meta, Claude, HF Chat, Dola) into a Roblox Studio agent via a local bridge + MCP.

Settings are stored in chrome.storage.local. No account, no telemetry.
